# ExactSplice

[English](README.md) · [Русский](README.ru.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Українська](README.uk.md)

**Монтаж видео с точностью до кадра и минимальным перекодированием.**

ExactSplice — открытый локальный видеоредактор на базе FFmpeg, первоначально созданный как Video Hide для скрытия конфиденциальных фрагментов записей. Браузер и Python-сервер работают на одном устройстве, облачные сервисы не нужны.

## Состояние проекта

Опорная версия — [Video Hide v0.3.1](https://github.com/l3chat/ExactSplice/releases/tag/v0.3.1). Расширенный редактор 0.4 разрабатывается. Портативные сборки Windows, Linux и macOS запланированы, но пока недоступны.

## Установка

На Android установите Termux и выполните команды ниже. На Linux установите Python 3 и FFmpeg (включая ffprobe, libx264 и drawtext), клонируйте репозиторий и запустите сервер.

### Android / Termux

```sh
pkg install python ffmpeg git
termux-setup-storage
git clone --branch v0.3.1 https://github.com/l3chat/ExactSplice.git
cd ExactSplice
python gui.py
```

### Linux

```sh
git clone --branch v0.3.1 https://github.com/l3chat/ExactSplice.git
cd ExactSplice
python3 gui.py /path/to/videos
```

Откройте http://127.0.0.1:8765 в браузере. Прежний интерфейс пока на русском. Путь к папке видео можно передать аргументом командной строки.

## Работа

1. Выберите видео; возможность воспроизведения зависит от поддержки кодека браузером.
2. Для Smart найдите ключевые кадры. Используйте масштабируемую шкалу, переходы по ключевым кадрам и покадровый шаг для установки начала и конца.
3. Добавьте каждый интервал. Пересекающиеся и смежные интервалы объединяются; корректный незавершённый выбор также включается в экспорт.
4. Настройте цвет фона, цвет и размер таймера и включите предпросмотр. В экспорт попадает таймер, но не надпись предпросмотра.
5. Сохраните или откройте JSON-проект: он содержит пути и настройки, а не видео. Проекты 0.2 загружаются; при необходимости выберите Smart Exact вручную.
6. Выберите режим, звук, CRF и новое имя MP4. Следите за прогрессом и журналом; не закрывайте сервер до завершения.

## Режимы экспорта

- **Full:** перекодирует всё видео в H.264; CRF 18 по умолчанию.
- **Smart:** расширяет интервалы наружу до существующих ключевых кадров и копирует остальные GOP.
- **Smart Exact (экспериментальный):** перекодирует только затронутые GOP, маскирует по номерам кадров и создаёт IDR на внутренних границах. Остальные GOP копируются. Граница между кадрами округляется вверх до следующего кадра; таймер отсчитывает до фактического конца скрытия.

## Совместимость и конфиденциальность

Smart требует обычного H.264 yuv420p CFR, квадратных пикселей, нулевого начала и подходящих внутренних ключевых кадров с обеих сторон интервалов. Иначе используйте Full. Проверяются число пакетов, временные метки и декодированные кадры около склеек; ошибка препятствует публикации. Необязательная полная проверка сравнивает декодированные кадры результата с подготовленными фрагментами; в Full лишь проверяет декодирование. Это не гарантия конфиденциальности: просмотрите все скрытые интервалы и прослушайте результат перед передачей.

Сохраняется только первая звуковая дорожка. При заглушении она перекодируется в AAC с запасом 0,25 с с обеих сторон; проверьте результат. Субтитры, главы и исходные метаданные не копируются. Исходники не изменяются. Размер результата не гарантируется; оценка не учитывает переменный битрейт и новые данные.

## Прогресс и отмена

Прогресс приблизительный; отображаются этап, скорость FFmpeg, прошедшее и оставшееся время, объём текущей операции при наличии данных. Поиск ключевых кадров не имеет точного процента. Кнопка остановки отправляет SIGTERM группе процессов; при штатной отмене временные файлы удаляются без публикации результата. При принудительном завершении рядом с результатом могут остаться каталоги .video-hide-* с конфиденциальными кадрами. Удаляйте их только после остановки обработки.

## Тестирование и исправление DTS

В 0.3.1 нормализуются DTS при сохранении PTS. На синтетических видео Linux сообщалось об успешных тестах с 0, 1 и 2 B-кадрами, проверкой Smart Exact и отменой. Пользователь также подтвердил обработку длинной записи Zoom на Android. Широкое тестирование устройств, кодеков и заглушения звука ещё не завершено.

# ExactSplice

[English](README.md) · [Русский](README.ru.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Українська](README.uk.md)

**Монтаж відео з точністю до кадру та мінімальним перекодуванням.**

ExactSplice — відкритий локальний відеоредактор на основі FFmpeg, спочатку створений як Video Hide для приховування конфіденційних фрагментів записів. Браузер і Python-сервер працюють на одному пристрої; хмарні сервіси не потрібні.

## Стан проєкту

Опорна версія — [Video Hide v0.3.1](https://github.com/l3chat/ExactSplice/releases/tag/v0.3.1). Розширений редактор 0.4 розробляється. Портативні збірки для Windows, Linux і macOS заплановані, але ще недоступні.

У гілці `develop` новий редактор доступний за `/editor`: вирізання, копіювання, вставка, видалення, переміщення, заміна, поділ, приховування, зовнішні вставки та Undo/Redo. Експорт поки повністю перекодовує відео, потребує однакової частоти кадрів і не перевірений на реальних файлах. Універсальний Smart Exact ще не реалізовано. Див. [опис alpha](docs/editor-alpha.md).

## Встановлення

На Android встановіть Termux і виконайте наведені команди. На Linux встановіть Python 3 та FFmpeg (з ffprobe, libx264 і drawtext), клонуйте репозиторій і запустіть сервер.

### Android / Termux

```sh
pkg install python ffmpeg git
termux-setup-storage
git clone -b develop https://github.com/l3chat/ExactSplice.git
cd ExactSplice
python gui.py
```

### Linux

```sh
git clone -b develop https://github.com/l3chat/ExactSplice.git
cd ExactSplice
python3 gui.py /path/to/videos
```

Відкрийте http://127.0.0.1:8765 у браузері. Попередній інтерфейс наразі російськомовний. Шлях до теки з відео можна передати аргументом командного рядка.

## Робота

1. Виберіть відео; відтворення залежить від підтримки кодека браузером.
2. Для Smart знайдіть ключові кадри. Використовуйте масштабовану шкалу, переходи між ключовими кадрами та покадровий крок для встановлення початку й кінця.
3. Додайте кожен інтервал. Суміжні інтервали та ті, що перетинаються, об’єднуються; коректний незавершений вибір також експортується.
4. Налаштуйте колір фону, колір і розмір таймера та ввімкніть попередній перегляд. Експорт містить зворотний відлік, але не напис попереднього перегляду.
5. Збережіть або відкрийте JSON-проєкт: він містить шляхи й налаштування, а не відео. Проєкти 0.2 завантажуються; за потреби виберіть Smart Exact вручну.
6. Виберіть режим, звук, CRF і нове ім’я MP4. Стежте за прогресом і журналом; не закривайте сервер до завершення.

## Режими експорту

- **Full:** перекодовує все відео в H.264; CRF 18 за замовчуванням.
- **Smart:** розширює інтервали назовні до наявних ключових кадрів і копіює решту GOP без перекодування.
- **Smart Exact (експериментальний):** перекодовує лише зачеплені GOP, маскує за номерами кадрів і створює IDR на внутрішніх межах. Решта GOP копіюються. Межа між кадрами округлюється вгору до наступного кадру показу; таймер відлічує до фактичного кінця приховування.

## Сумісність і конфіденційність

Smart потребує звичайного H.264 yuv420p, сталої частоти кадрів (CFR), квадратних пікселів, нульового початку й відповідних внутрішніх ключових кадрів з обох боків інтервалів. Інакше використовуйте Full. Перевіряються кількість пакетів, часові мітки показу та декодовані кадри біля стиків; помилка унеможливлює публікацію. Необов’язкова повна перевірка порівнює декодовані кадри результату з підготовленими фрагментами; у Full лише перевіряє декодування. Це не гарантує конфіденційності: перегляньте всі приховані інтервали й прослухайте результат перед поширенням.

Зберігається лише перша звукова доріжка. При вимкненні звуку вона перекодовується в AAC із запасом 0,25 с з обох боків; перевірте результат. Субтитри, розділи та вихідні метадані не копіюються. Джерела не змінюються. Розмір результату не гарантований; оцінки не враховують змінний бітрейт і нові дані.

## Прогрес і скасування

Прогрес приблизний: показано етап, швидкість FFmpeg, минулий і приблизний залишковий час, обсяг даних поточної операції за наявності. Пошук ключових кадрів не має точного відсотка. Кнопка зупинки надсилає SIGTERM групі процесів; за штатного скасування тимчасові файли видаляються без публікації результату. Примусове завершення може залишити теки .video-hide-* з конфіденційними кадрами поруч із результатом. Видаляйте їх лише після зупинки обробки.

## Тестування та виправлення DTS

У 0.3.1 нормалізуються DTS зі збереженням PTS. Повідомлялося про успішні тести синтетичних відео в Linux із нулем, одним і двома B-кадрами, перевіркою Smart Exact і скасуванням. Користувач також підтвердив обробку довгого запису Zoom на Android. Широке тестування пристроїв, кодеків і приховування звуку ще не завершено.
